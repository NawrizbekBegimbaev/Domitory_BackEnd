> Дата: 2026-03-11
> Стек: React (веб-панель) + Flutter (мобильное приложение)
> Команда: 1 fullstack-разработчик
> Связан с: ProjectChecklist.md (бэкенд)

---

## Стратегия для solo-разработчика

Ты один — значит нужно максимально использовать готовые решения:

| Задача | Не писать с нуля | Использовать |
|--------|------------------|-------------|
| UI-компоненты | Не рисовать кнопки/таблицы | **Ant Design** (React) / **Material 3** (Flutter) |
| Таблицы с фильтрами | Не писать свою таблицу | **Ant Design Table** (сортировка, фильтры, пагинация из коробки) |
| Формы | Не писать валидацию вручную | **Ant Design Form** + **React Hook Form** |
| Роутинг | — | **React Router v6** |
| HTTP-клиент | — | **Axios** с interceptors для JWT |
| Состояние | Не усложнять | **Zustand** (проще Redux, хватит на 100%) |
| Графики | Не писать SVG | **Recharts** или **Ant Design Charts** |
| Mobile навигация | — | **go_router** (Flutter) |
| Mobile HTTP | — | **Dio** (Flutter) |
| Mobile состояние | — | **Riverpod** (Flutter) |
